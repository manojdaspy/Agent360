What is template_prompt?
It's a persistent notepad for the AI agent. Templates are saved to vibescode_templates.json on disk and survive server restarts. The agent can save and load any text — plans, prompts, task checklists — across sessions.

Real Use Cases
1. Save the system prompt once, load it every new chat
AGENT_CALL {"op":"template_prompt","action":"save","name":"system/vibescode","tag":"system","content":"You are VibesCode Agent..."}
Then in any new conversation:
AGENT_CALL {"op":"template_prompt","action":"get","name":"system/vibescode"}
2. Save a multi-step task plan at the start of a big feature
AGENT_CALL {"op":"template_prompt","action":"save","name":"feature/auth-refactor","tag":"plan","content":"## Goal\nRefactor auth to JWT\n## Steps\n1. Read auth.py\n2. Write new jwt.py\n3. Update routes\n4. Run tests"}
Later, mid-task, load it to remember what's left:
AGENT_CALL {"op":"template_prompt","action":"get","name":"feature/auth-refactor"}
3. List all saved plans
AGENT_CALL {"op":"template_prompt","action":"list","tag":"plan"}
4. Delete when done
AGENT_CALL {"op":"template_prompt","action":"delete","name":"feature/auth-refactor"}

## ━━ TEMPLATE PROMPT — PERSISTENT MEMORY ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

`template_prompt` is the agent's **long-term memory**. Templates are saved to
disk and survive server restarts. Use them to preserve plans, system prompts,
and task checklists across sessions.

### When to use

| Situation | Action |
|-----------|--------|
| Starting a multi-step feature | `save` a plan with all steps |
| Resuming work in a new chat | `list` then `get` the saved plan |
| Storing the system prompt | `save` under `system/vibescode` |
| Task fully complete | `delete` the plan |

### Rules
- **Always `list` on session start** — check if a plan exists before asking the user
- **Save a plan before long tasks** — so any future session can resume without re-explaining
- **One plan per feature** — name it `feature/<name>` or `task/<name>`
- **Update the plan** after completing each step — `save` overwrites the old one
- **Delete when done** — keep the template store clean

### Tags
| tag | purpose |
|-----|---------|
| `plan` | multi-step task checklist |
| `system` | system prompts |
| `task` | single focused tasks |
| `general` | anything else |

### Examples

Save a plan at the start of a feature:
AGENT_CALL {"op":"template_prompt","action":"save","name":"feature/auth-refactor","tag":"plan","content":"## Goal\nRefactor auth to JWT\n## Steps\n1. Read auth.py\n2. Write jwt.py\n3. Update routes\n4. Run tests\n## Status\nStep 1 done"}

Load it in a new session:
AGENT_CALL {"op":"template_prompt","action":"get","name":"feature/auth-refactor"}

Update after completing a step:
AGENT_CALL {"op":"template_prompt","action":"save","name":"feature/auth-refactor","tag":"plan","content":"## Goal\nRefactor auth to JWT\n## Steps\n1. ✅ Read auth.py\n2. ✅ Write jwt.py\n3. Update routes\n4. Run tests\n## Status\nStep 3 in progress"}

List all plans:
AGENT_CALL {"op":"template_prompt","action":"list","tag":"plan"}

Delete when done:
AGENT_CALL {"op":"template_prompt","action":"delete","name":"feature/auth-refactor"}
