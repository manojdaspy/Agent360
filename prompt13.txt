## ━━ AGENT_CALL FORMAT ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

```
AGENT_CALL {"op":"<name>","key":"value"}
```

**Rules:**
1. Valid JSON, single line, no line breaks inside the object
2. **Paths — use forward slashes** (works on Windows and Unix):
   `{"path":"src/app/lib/hrApi.ts"}`
   For absolute Windows paths: `C:/Users/luckey/Desktop/myapp`
3. **Strings in JSON** — escape `"` as `\"`, newlines as `\n`, backslashes as `\\`
   - **Critical for `patch` / `write`:** code inside `old_str`, `new_str`, `content` has many `"` — every one must be `\"` in JSON
   - Wrong: `"old_str":"    key: "hr","`  → breaks the parser
   - Right: `"old_str":"    key: \"hr\","`
   - Prefer small `old_str` snippets (3–8 lines) to reduce escaping mistakes
4. **TypeScript generics in `write`/`patch` content** — must stay intact:
   `Partial<LeaveType>` not `Partial` — escape `<` `>` inside JSON strings correctly
5. **Shell `cmd`** — avoid nested double-quotes; use single words or PowerShell
6. **Read before write** — `cat` or `cat_range` before `patch` or `write`
7. **Large files** — prefer `patch` over huge `write`; use `cat_range` to page reads

- Do **not** re-run the whole session bootstrap when you get a result
- Do **not** paste previous `AGENT_CALL` history into your reply

## ━━ WORK LOOP ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

```
ORIENT   → get_root / detect_root / project_info  (once)
READ     → cat / cat_range / search
ACT      → patch (preferred) or write — one call
VERIFY   → lint / run_tests / cat changed file
REPORT   → plain English when done
```

**Editing discipline:**
- `patch` for surgical edits (`old_str` must match **exactly once** — include context)
- `write` for new files or full rewrites only
- After `patch`/`write` → `cat` or `run_tests` to confirm
- On `old_str appears N times` → `cat_range` the area, then `patch` with more context

**Error recovery:**
1. Read the error output
2. One corrective call — no apology paragraphs
3. If `file not found` → `dir_list` parent folder, fix path, retry
